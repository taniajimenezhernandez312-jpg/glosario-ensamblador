Glosario Interactivo:
Lenguaje Ensamblador

Basado en el Estándar IEEE 610.12

1

MOV

Mueve datos entre registros o memoria.

Ejemplo: MOV AX, BX
2

ADD

Suma dos operandos y guarda el resultado.

Ejemplo: ADD AL, 5
3

SUB

Resta el operando fuente del operando destino.

Ejemplo: SUB AX, 10h
4

.code

Marca el inicio del segmento donde se escriben las instrucciones.

Uso: .code
5

.data

Marca el inicio del segmento donde se definen las variables.

Uso: .data
6

.model small

Configura el modelo de memoria (segmentos de datos y código de hasta 64KB).

Uso: .model small
7

.stack 100h

Reserva 256 bytes para el uso de la pila (stack).

Uso: .stack 100h
8

db (Define Byte)

Reserva 8 bits de memoria para un dato o carácter.

Ejemplo: var1 db 10
9

dw (Define Word)

Reserva 16 bits de memoria (2 bytes).

Ejemplo: var2 dw 1000h
10

dup

Operador que permite repetir un valor varias veces al reservar memoria.

Ejemplo: db 5 dup(0)
11

end

Indica el fin del archivo fuente.

Uso: end main
12

endp

Marca el final de un procedimiento (proc).

Uso: main endp
13

equ

Crea una constante simbólica o un alias para una dirección.

Ejemplo: PI equ 3
14

main

Nombre común para el procedimiento principal del programa.

Uso: main proc
15

proc

Define el inicio de un procedimiento o función.

Ejemplo: mi_func proc
16

AAM

Ajuste ASCII después de la multiplicación; separa unidades y decenas.

Instrucción: AAM
17

CMP

Compara dos valores restándolos (afecta las banderas de estado).

Ejemplo: CMP AX, 0
18

DEC

Resta 1 al valor de un registro o posición de memoria.

Ejemplo: DEC CX
19

DIV

Divide el acumulador entre un operando (8 o 16 bits).

Ejemplo: DIV BL
20

INC

Suma 1 al valor de un registro o posición de memoria.

Ejemplo: INC SI
21

INT 21h

Ejecuta una interrupción del DOS para servicios de entrada y salida.

Uso: INT 21h
22

JA / JB

Saltos condicionales: JA (mayor) y JB (menor) para números sin signo.

Ejemplo: JA etiqueta
23

JE / JZ

Salto si es igual o si el resultado es cero.

Ejemplo: JE salir
24

JMP

Salto incondicional a una etiqueta específica.

Ejemplo: JMP inicio
25

LOOP

Decrementa CX y salta si no ha llegado a cero.

Uso: LOOP ciclo
26

MUL

Multiplica el acumulador por un operando.

Ejemplo: MUL BL
27

PUSH / POP

PUSH guarda un valor en la pila; POP lo recupera.

Ejemplo: PUSH AX
28

XOR

Operación lógica "OR Exclusivo". Útil para limpiar registros.

Ejemplo: XOR AX, AX
29

AX / BX / CX / DX

Registros generales (Acumulador, Base, Contador, Datos).

Registros de 16 bits
30

OFFSET

Obtiene la dirección de memoria exacta (desplazamiento) de una variable.

Ejemplo: MOV DX, OFFSET msg
31

$ (Signo Pesos)

Fin de cadena para la función 09h de la INT 21h.

Ejemplo: db "Hola$"
32

0Ah / 0Dh

Salto de línea (Line Feed) y retorno de carro (Carriage Return).

Códigos: 10 y 13 decimal
33

AH = 09h

Función para imprimir una cadena de texto en pantalla.

MOV AH, 09h
34

AH = 4Ch

Finalizar el programa y volver al sistema.

MOV AH, 4Ch
