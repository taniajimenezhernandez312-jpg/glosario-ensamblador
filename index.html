Glosario Interactivo:
Lenguaje Ensamblador

Basado en el Estándar IEEE 610.12

1

AAA

Ajuste ASCII para la suma.

Instrucción: AAA
2

AAD

Ajuste ASCII antes de la división.

Instrucción: AAD
3

AAM

Ajuste ASCII tras la multiplicación (separa unidades y decenas).

Instrucción: AAM
4

AAS

Ajuste ASCII para la resta.

Instrucción: AAS
5

ADC

Suma con acarreo (Carry).

Ejemplo: ADC AX, BX
6

ADD

Suma simple de dos operandos.

Ejemplo: ADD AL, 5
7

AND

Operación lógica "Y".

Ejemplo: AND AL, 0Fh
8

CALL

Llama a un procedimiento o función.

Ejemplo: CALL mi_proceso
9

CBW

Convierte un Byte en Word (extiende el signo de AL a AX).

Instrucción: CBW
10

CLC

Limpia la bandera de acarreo (Carry Flag = 0).

Instrucción: CLC
11

CLD

Limpia la bandera de dirección (procesamiento hacia adelante).

Instrucción: CLD
12

CLI

Desactiva interrupciones externas.

Instrucción: CLI
13

CMC

Complementa (invierte) la bandera de acarreo.

Instrucción: CMC
14

CMP

Compara dos valores (resta interna que solo afecta banderas).

Ejemplo: CMP AX, 10
15

CWD

Convierte Word en Double Word (extiende signo de AX a DX:AX).

Instrucción: CWD
16

DAA

Ajuste decimal para la suma (usado en BCD).

Instrucción: DAA
17

DAS

Ajuste decimal para la resta.

Instrucción: DAS
18

DEC

Decrementa en 1 (resta 1).

Ejemplo: DEC CX
19

DIV

División entera sin signo (usa AX o DX:AX).

Ejemplo: DIV BL
20

HLT

Detiene el procesador hasta la próxima interrupción.

Instrucción: HLT
21

IDIV / IMUL

División y Multiplicación entera con signo.

Ejemplo: IMUL BL
22

INC

Incrementa en 1 (suma 1).

Ejemplo: INC SI
23

INT

Genera una interrupción de software (ej. int 21h).

Uso: INT 21h
24

JA / JAE / JB / JBE

Saltos condicionales para números sin signo (mayor, mayor igual, menor, menor igual).

Ejemplo: JA etiqueta
25

JC / JCXZ

Salto si hay acarreo o si el registro CX es cero.

Ejemplo: JCXZ salir
26

JE / JZ

Salto si es igual o si el resultado es cero (ZF = 1).

Ejemplo: JZ es_cero
27

JG / JGE / JL / JLE

Saltos condicionales para números con signo.

Ejemplo: JG mayor_con_signo
28

JMP

Salto incondicional (siempre salta).

Ejemplo: JMP inicio
29

JNE / JNZ

Salto si no es igual o no es cero (ZF = 0).

Ejemplo: JNZ continuar
30

LEA

Carga la dirección efectiva (puntero) en un registro.

Ejemplo: LEA DX, cadena
31

LOOP / LOOPE / LOOPNE

Ciclos automáticos basados en el registro CX.

Ejemplo: LOOP ciclo
32

MOV

Mover o copiar datos de un lugar a otro.

Ejemplo: MOV AX, @data
33

NEG / NOT

NEG cambia el signo; NOT invierte los bits (lógico).

Ejemplo: NEG AX
34

PUSH / POP / PUSHA / POPA

Operaciones con la pila (individuales o todos los registros).

Ejemplo: PUSH AX
35

RET

Regresa de un procedimiento (vuelve a la dirección de la pila).

Instrucción: RET
36

SHL / SHR / SAL / SAR

Desplazamientos lógicos y aritméticos de bits.

Ejemplo: SHL AL, 1
37

XOR

Operación lógica "O exclusiva" (usada para poner registros en 0).

Ejemplo: XOR AX, AX
38

AX / AH / AL

Registro acumulador (16 bits, Parte Alta, Parte Baja).

Uso: Operaciones aritméticas
39

BX / CX / DX

Registros Base, Contador y Datos (y sus partes H/L).

Registros generales
40

SI / DI / BP / SP

Índices de origen/destino y punteros de pila.

Registros de índice y puntero
41

CS / DS / SS / ES

Registros de Segmento (Código, Datos, Pila, Extra).

Manejo de memoria
42

DB / DW / DD

Define Byte (8), Word (16) o Double Word (32 bits).

Ejemplo: var db 0
43

OFFSET

Obtiene la dirección de desplazamiento de una variable.

Ejemplo: MOV DX, OFFSET msg
44

PROC / ENDP / END

Inicio y fin de procedimientos y fin del archivo fuente.

Estructura del programa
45

$ / ?

Posición actual ($) y reserva de espacio no inicializado (?).

Ejemplo: db 10 dup(?)
46

titulo / msg_f / msg_c

Etiquetas usadas para tus cadenas de texto y mensajes.

Uso: En segmento .data
47

filas / columnas / cont_f

Variables para control de bucles y dimensiones de figuras.

Uso: Contadores de bucles
48

cicloLoop / cicloLoop1

Etiquetas de control para saltos y bucles anidados.

Uso: Etiquetas de destino
49

AH = 01h / 02h

Leer carácter con eco / Escribir un carácter en pantalla.

INT 21h
50

AH = 09h / 0Ah

Mostrar cadena ($) / Entrada de cadena con buffer.

INT 21h
51

AH = 4Ch

Terminar programa con código de retorno.

MOV AH, 4Ch
52

0Ah / 0Dh

Salto de línea (LF) y Retorno de carro (CR).

Valores: 10 y 13
53

30h

Valor para convertir el dígito '0' (ASCII a decimal).

Uso: Ajuste numérico
54

02h / 0Eh

Símbolos especiales: Cara feliz y Nota musical.

Caracteres gráficos
